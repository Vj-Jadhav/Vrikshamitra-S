# 🌱 Vrikshamitra – Gamified Green Learning

Vrikshamitra is a gamified environmental education platform designed for
schools and colleges. It combines interactive 2D games, AR/VR experiences,
and real-world environmental activities to make eco-learning engaging and
practical.

The platform provides dedicated modules for students, faculty, institutes,
and government/NGO stakeholders, enabling activity assignment, submission
verification, progress tracking, leaderboards, reports, and eco-achievements.
